# Wallpapers

CapsuleOS ships no bundled wallpapers yet. `installer/starter-wallpapers/` is an empty seed directory (see its `README.txt`) until a licensed Golden-Gate-at-night set is dropped in before release.

In the meantime, search for Golden-Gate-at-night wallpapers on [Unsplash](https://unsplash.com/s/photos/golden-gate-bridge-night) or [Wallhaven](https://wallhaven.cc/search?q=golden+gate+bridge+night) and drop whatever you like into `~/CapsuleOS/wallpapers`.

The wallpaper picker's folder is configurable from **Settings → Wallpaper**, so you can point it at any directory of your own images instead.

All art belongs to the original creators. If you use someone else's work, credit them.
